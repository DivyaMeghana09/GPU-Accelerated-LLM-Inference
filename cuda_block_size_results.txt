========================================
CUDA BLOCK SIZE EXPERIMENT
========================================

GPU: NVIDIA Tesla T4
Operation: Vector Addition
Elements: 10,000,000
Runs per Configuration: 10

RESULTS
----------------------------------------

Threads per Block: 128
Blocks: 78,125
Average GPU Kernel Time: 0.00061117 seconds

Threads per Block: 256
Blocks: 39,063
Average GPU Kernel Time: 0.00058153 seconds

Threads per Block: 512
Blocks: 19,532
Average GPU Kernel Time: 0.00059874 seconds

BEST CONFIGURATION
----------------------------------------

Threads per Block: 256
Average GPU Kernel Time: 0.00058153 seconds

CONCLUSION
----------------------------------------

For this vector-addition kernel and
10-million-element workload on the
NVIDIA Tesla T4, 256 threads per block
produced the lowest average measured
kernel execution time.

The performance differences were small,
so this result should not be generalized
to all CUDA kernels or workloads.
