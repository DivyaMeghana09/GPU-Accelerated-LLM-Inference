========================================
FINAL CONCLUSION
========================================

The project demonstrated that GPU
acceleration significantly improved
LLM inference throughput compared
with the tested CPU configuration.

FP16 and batch inference provided
useful performance improvements.

INT8 quantization and torch.compile
did not improve performance for this
specific workload.

GPU profiling showed that matrix
multiplication was a major part of
the workload.

A custom CUDA kernel experiment was
also implemented to understand GPU
parallel execution using threads,
blocks, and grids.

The main lesson of the project was:

Measure
→ Find the bottleneck
→ Optimize
→ Measure again
→ Keep what works
